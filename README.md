# Honours Dissertation – Road Traffic Fatality Prediction in Gauteng's Festive Seasons

## About the Project

This project forms part of an Honours in Data Science research study titled **Predicting Road Traffic Fatalities in Gauteng During the Festive Season Using Machine Learning Techniques**.

The study investigates the application of machine learning techniques to predict road traffic fatalities during festive periods in Gauteng, South Africa.

## Project Components

- `app.py` – Streamlit-based graphical user interface.
- `gauteng_festive_road_fatality_prediction.ipynb` – Research analysis and experimentation.
- `requirements.txt` – Python dependencies.
- `.gitignore` – Files excluded from version control.

## Technologies

- Python
- Pandas
- Scikit-learn
- Streamlit
- Joblib
- Jupyter Notebook

## Dataset

The research uses road traffic crash data obtained from the Road Traffic Management Corporation (RTMC), covering Gauteng.

The original dataset is not included in this repository.

## Running the Application

Install the required dependencies:

`pip install -r requirements.txt`

Launch the application:

`streamlit run app.py`

Open the local URL displayed in your terminal to access the application.
